# 白板家教｜方向（給做 App 的人改）

日期：2026-11-23  
狀態：**已定方向，請依這份改課堂與白板**  
對標：ahaboard.ai（邊講邊畫的 AI 白板家教）

本文件優先於 `docs/AI智慧教學工具-需求.md`（2026-11-18）裡相衝突的條文，尤其是「上課方式」「測驗與檢討」和「圖表怎麼來」。雷射筆、引線註記、匯出 PDF、進度保存、不存學生原聲，那些仍有效。

像素、字體、顏色、框架選型不在這份裡。要改的是產品契約：我們是家教，不是播課機。

---

## 1. 新定位

AI 是坐在對面的**家教老師**：先搞清楚學生卡在哪，再邊講邊把每一步畫在白板上。講到學生會為止。

不再是：備好講稿後一路往下念，等學生自己按暫停。

學生感覺應該是「有人看著我這題」，不是「我在操作一套上課工具」。

---

## 2. 舊契約作廢（請從產品裡拿掉）

以下行為視為錯誤，不要再當正確實作：

| 舊規定 | 改成 |
| --- | --- |
| AI 不主動停下來確認學生懂了沒有，一路講到打斷為止 | 該停就停。問一句、等學生試下一步，再畫、再講 |
| 首頁切「白板／Chat」兩種產品模式 | 首頁切學生意圖：**主題／備考／作業** |
| 測驗只在學生按「測驗」或打出「出題」才開始 | 主題課告一段落要給小測；作業模式用提示帶學生自己解，不另開一頁才算上課 |
| 通用圖用模型自由畫 SVG；畫不出來只寫 caption 也行 | 要算的圖必須算出來再畫。禁止用「只寫圖說」交差 |
| 課堂上同時擺滿離開、全螢幕、測驗、PDF、回放、螢光筆、雷射、翻頁、教材側欄 | 第一次上課只看見白板＋家教在說話／在畫。其他工具用到再出現 |

保留：學生隨時可以打斷；打斷後不要丟失這堂課的板書與進度。

---

## 3. 三種開課意圖

開課前學生選一種。這會改變家教怎麼備課、怎麼停、怎麼畫。不要做成同一個講稿換皮。

### 主題

學生要搞懂一個觀念。例如「導數到底是什麼意思」。

- 從學生已經會的地方開始，不要從頭背定義。
- 邊講邊畫。講完一個觀念，停下來問一句，等學生用自己的話或在板上指出來。
- 告一段落給複習重點＋幾題小測。錯的再用同一張板講一次。

### 備考

學生丟講義、範圍或連結，明天要考。

- 把範圍收成講解順序：重點、易錯點、再出題。
- 易錯點要畫出來或標在已有的圖上，不要只印一行字。
- 小測針對這份教材，錯的再講。

### 作業

學生卡在某一題。貼題目、拍照、上傳都可以。

- **不直接給最終答案。**
- 一次一個提示，請學生做下一步，檢查思路。
- 每一步都畫在板上：列式、圖、箭頭。
- 學生把寫過的過程給家教看時，指出出錯的那一行並說明原因。
- 學生說「直接給我答案」才把完整解法畫完；預設當家教，不當解答機。

Chat 不要跟白板平起平坐。純文字問答可以收進主題，或當白板旁的對話，不要讓學生先選「要不要畫板」。

## 4. 家教怎麼上課

開口之前，家教自己先寫一份**學生看不到的教案**（不必畫成設定頁）：

1. 這題／這個觀念的完整解法或正確關係
2. 這程度學生常錯在哪
3. 講解順序：先畫什麼、再問什麼、何時才寫公式
4. 哪些圖必須算出來（函數、交點、力的分量、波形）

沒有這份教案，不准開始在白板上畫函數或受力圖。

上課節奏：

- 語音可以講，板書跟著出現。這點與舊需求相同。
- **圖留在板上，對話繼續。** 學生追問時，優先在同一張圖上加箭頭、加註、並排一條新式子，不要清掉重畫一整頁。
- 家教問學生時，語音與板書都停在「等你」。學生答了再繼續。超時可輕聲提示，不要自己把答案講完。
- 學生說「繼續講就好」時，才可以連講較長一段；仍要一段一圖，不要一次倒上整頁。
- 重新解釋＝換個畫法或再拉一條註記，不是把舊圖塗掉。

下課要帶走：這堂課的板、重點、小測結果。主題課結束沒有小測，算沒做完。

## 5. 白板向 ahaboard 看齊

精細圖教學的原則就一句：**圖要準，就不要請模型目測去畫。**

波的示意已經做對了（振幅、波長算出正弦，波峰波谷逐步出現）。同一套規則推到函數圖、受力圖、格子圖。

### 5.1 先算，再畫

| 可以 | 不可以 |
| --- | --- |
| 給前端資料：函數式、定義域、要標的點／交點，由 App 畫座標與曲線 | 把 `y=x²` 交給模型產出一條看起來像拋物線的 SVG path |
| 受力：物體＋一支一支有標籤的力箭，分量用三角函數算出方向 | 一張「大概有幾個箭頭」的示意 PNG／自由 SVG |
| 波形：振幅、波長、相位算出來，逐步加平衡位置、波峰、標註 | 模型手繪一條彎線當波 |
| 棋盤方格：基因型進格子，機率由組合算出 | 模型畫一個長得像表格的圖 |

示意類（生物週期、流程、地圖、歷史對照）可以走示意圖，但仍要逐步出現、有標籤，不能整張一次貼上。

### 5.2 一次只加一個圖元

同一張圖的構成要可逐步揭示，例如：

- 拋體：先弧線 → 再兩顆球 → 再受力（只剩重力）
- 受力：先物體 → 重力 → 法線 → 摩擦力 → 再列式
- 函數：先座標軸 → 第一條曲線 → 第二條 → 交點
- 遺傳：先空的四格 → 一格一格填

禁止：備課把一整張示意當一個區塊一次倒上板。語音講到哪，圖才出現到哪。

### 5.3 圖要能並排、能留下來

兩條式子、兩條曲線、改錯前後，必須能同時留在看得見的板上，讓學生看出「斜率相同不是同一條線」。

重開這堂課時，已畫上的圖必須還在。不要只存講稿不存圖。

### 5.4 第一批科目圖元（請依此做，不要先做萬能畫板）

**P0 必須有**

- 座標＋函數曲線（可多條）＋標點＋交點
- 受力圖（物體、有標籤的箭、可逐步加）
- 波形（沿用現有波圖思路，變成通用參數，不要只服務「波的性質」那一課）
- 文字、公式、引線註記、雷射筆（舊需求保留）

**P1 接著做**

- 棋盤方格（遺傳）
- 並排比較（兩式、兩圖）
- 單位圓／角度
- 簡單幾何：三角形、輔助線、標角

**P2**

- 動畫、可調參數實驗（現有波實驗可留，當互動圖元的一種）
- 地圖、時間軸等文科示意

簡單圖形元素（直線、虛線、箭頭、括號、圓、矩形、點、座標軸、角度記號）改成**所有圖元都能用的零件**，不要再寫死在波圖裡。

模型的工作是選圖元、填資料（函數、力、格子內容、出現順序）。App 負責畫準。模型不要直接負責像素路徑。

## 6. 上課畫面（給 App，不是像素稿）

- **電子黑板是主舞台。** 對話是疊在課上的來往，不是另一個 Chat 頁。
- 第一次進課堂：白板＋家教正在畫／正在問。不要同時教學生使用十幾個工具。
- 打斷、發問、麥克風放在隨手可得的地方（底部一行即可）。
- 螢光筆、PDF、回放、雷射開關、教材原文：收進「需要時再打開」，不要跟板書搶視線。
- 學生作業模式更要像一張題＋家教在旁邊畫，不要跳去另一面「測驗白板」才開始解題。

語音、字幕可以留。字幕是現在這一句，不要變成歷史逐字稿牆。

---

## 7. 首頁

學生打開 App，問的是「你卡在哪」，不是「選白板還是 Chat」。

- 三個意圖分頁：主題／備考／作業。輸入框說明跟著換。
- 給能點的例子（可換一批）。點了就帶著那句話去開課，不要只填進空框。
- 附加檔案保留。能貼網址更好（講義、公開 PDF），沒有的話 P1 再做。
- 授課語言、年級放在開課附近或設定，不要擋在「開始」前面。
- 沒接模型時再帶去設定。已接上就不要先逛八個設定分頁。

空的「我的課」「筆記」不要跟開課框搶第一眼。有課再出現列表。

---

## 8. 請不要拆掉的優勢

對齊 ahaboard 是對齊**家教節奏＋算出來的圖**，不是做成網頁家教複製品。

一定要留：

- iPad、Apple Pencil、掌托、手寫筆記
- 打斷後接回這堂課未完成的進度（作業解完可以回到主題進度）
- 本機課、自選模型、記憶庫
- 雷射筆跟著講、引線註記
- 圖與進度重開還在（這點我們比對方穩，不要弄丟）

不要學：帳號牆才能開第一堂課、重開課圖消失、免費額度卡死課堂。

## 9. 給實作的優先順序

請照這個順序交，不要先做新的設定項或新的筆記功能。

1. **改上課契約**：三種意圖；作業不給最終答案；主題會停下來問；開口前有內部教案（解法／易錯／圖順序）。
2. **改圖怎麼來**：函數圖、受力圖、波形改為資料→App 繪製。拿掉「畫不出來只寫 caption」。自由 SVG 只留給示意類。
3. **改揭示**：同一張圖分步出現，講到才畫到。
4. **改首頁與課堂主畫面**：意圖開場；課堂上白板為主、工具收斂。
5. **下課**：重點＋小測留在這堂課。錯題可在同一張板上再講。

舊的「備好 4–8 段講稿再按開始一路念」可以當內部備課格式，但播放時必須能在段與段之間插入「問－等－再畫」。不要做成備課 JSON 播完才准問。

## 10. 怎樣算改對了（給驗收）

用這幾條人工走一次，全部成立才算這個方向落地：

1. 新用戶打開首頁，用「作業」點一題方程式，家教先問第一步該做什麼，白板上開始列式，**沒有先把 x 的值寫出來**。
2. 主題「兩條曲線交在哪」：板上出現的是算出來的座標與交點，兩條線同時留著，能看出交點；不是一張手繪示意。
3. 物理受力：箭頭一支一支出現，每支有標籤，然後才出現方程式。
4. 學生中途問「為什麼是這支箭」，家教在**同一張受力圖**上加註或加雷射，不問到另一頁空白板重講。
5. 主題課告一段落出現小測；答錯會指回剛才那張圖。
6. 離開再進來，圖還在。
7. 課堂第一眼不是工具列教學。

做不到第 1、2、6 條，就還是舊的講課老師，只是換了文案。
