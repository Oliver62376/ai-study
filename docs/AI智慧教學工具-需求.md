# AI 智慧教學工具｜需求

日期：2026-11-18

本文件只記錄已經確定的產品需求。技術實作、架構與介面像素配置不在這份文件裡。

## 核心定位

讓 AI 成為一位能自主備課、講課、板書、演示和回答問題的老師。

學生提供教材後，AI 不只是回答問題，而是主動帶領學生學習教材內容。

## 已確定的上課方式

- 語音講課為主：AI 說話，板書跟著講解出現。
- 學生可以隨時用語音或文字打斷。
- 學生可以要求補充、重新解釋或提出問題。
- 回答或補充完畢後，AI 接續原本尚未完成的課程。
- AI 不主動停下來確認學生懂了沒有，一路講到學生打斷為止。
- 學生可以要求進入測驗。測驗與檢討結束後，接續原本尚未完成的課程。
- AI 自行決定教學順序、內容、講解方式，以及何時插入圖表、動畫或互動元件。

## 教材

- 支援上傳講義、課本及其他學習資料。
- AI 能理解教材內容，包含文字、公式、圖片及圖表。
- 根據教材規劃教學順序與內容。
- 教學時能對應原始教材，避免偏離學習範圍。
- 預設只講教材範圍內的內容。
- 只有學生打斷並明確要求超出教材時，才使用教材以外的內容。
- 超出教材的說明結束後，回到原本尚未完成的進度。

## 教學對象與語言

這兩項不寫死在產品裡，由應用設定決定。預設值尚未指定。

| 設定項 | 可選內容 |
| --- | --- |
| 教學對象 | 年級、科目、程度 |
| 教學語言 | 跟著教材語言，或固定用某一種語言 |

高中數理（例如波的性質）是教材裡已舉出的教學情境，用來說明圖表、公式、動畫與互動元件要能配合語音講解。

## 上課畫面

- 電子黑板是主舞台。
- 逐字稿可以打開。
- 教材對應可以打開，用來對回原始教材。
- 逐字稿與教材對應不取代黑板。
- 具體版面配置尚未指定。

## 電子黑板

- 連續式板書，空間不足時自動換頁。
- 模擬老師在黑板上逐步講解：內容隨著講解逐步顯示，由上往下延伸。
- 文字由電腦字體呈現，不模擬手寫。
- 一般教學內容不開放直接編輯。
- 教學內容與白板呈現同步。

## 板書註記

AI 可以在已寫上的板書旁邊做筆記，用來講解某個觀念。

- 最基本的形式是拉一條引線：從公式、圖或某段文字拉出來，旁邊寫上短註。
- 註記跟著當下的講解出現。說到那個觀念時才拉線、才寫出旁註。
- AI 指定要指向的對象，以及旁註要寫的內容。線的走向和旁註放在哪裡，由板書自行排列，避免蓋住原本的內容。
- 註記是教學板書的一部分。學生不能直接改註記，也不能因為操作互動元件而改掉這些線和旁註。
- 重新解釋時可以再拉一條新的註記，或暫時標出既有註記。已寫上的註記不在講課途中被塗掉。

## 雷射筆

AI 有一支雷射筆，用來指出「現在正在講的位置」。這件事可行：板書上的文字、公式、圖形和註記都有明確對象，雷射筆只要跟著講解移到那個對象上。

雷射筆和引線註記分開。引線和旁註會留在黑板上；雷射筆只在講到的當下出現，講過去就移開，不寫進板書。

- 同一時間只有一個光點。
- AI 指定要指向的對象。光點由板書對到該對象的位置，可以在公式的某一項、圖上的某一個標記，或一段文字上。
- 光點跟著語音移動。說到下一個對象時，光點移過去。
- 對象在另一頁時，先顯示那一頁再指向它。這段講完，畫面回到正在書寫的那一頁。
- 學生打斷時，光點跟著講解暫停。補充說明若需要，可以指向已經寫上的內容。接回原進度後，光點回到原本要講的位置。
- 學生不能拿這支雷射筆，也不能因為操作互動元件而移動它。
- 上課紀錄開啟時，回放要包含光點怎麼移動。光點不留在保存下來的板書裡。

## 簡單圖形元素

AI 作圖、標示和做註記時，使用一套固定的簡單圖形，而不是自由手繪。需要講某個觀念時，AI 自行選用元素並組合。

| 元素 | 教學用途 |
| --- | --- |
| 直線、虛線 | 輔助線、平衡位置、對齊 |
| 單向箭頭、雙向箭頭 | 方向、作用、對應關係 |
| 引線 | 從對象拉到旁註 |
| 括號、大括號 | 把一組對象括起來說明 |
| 圓、橢圓 | 圈出重點、表示範圍 |
| 矩形 | 框出區域、當標示底 |
| 底線、標示框 | 強調文字或公式的一部分 |
| 點 | 標位置、標數據點 |
| 座標軸 | 函數、波形、實驗數據 |
| 角度記號 | 幾何、力與方向 |

規則：

- 文字與公式仍用電腦字體，圖形只負責線條、框和記號。
- 圖形依講解逐步出現，可以疊在既有板書上。
- 複雜的示意圖、動畫和互動元件仍然用各自的呈現方式。簡單圖形用來標示、註記，以及組出暫時沒有專用元件的示意。
- 元素不夠表達時，AI 仍要把該講的內容講完，並用文字、公式或下一步能用的圖形標清楚。不因為少了一種圖形就跳過那個觀念。

## 圖表、科學示意圖與動畫

AI 依照教學內容選擇呈現方式。

| 呈現方式 | 使用情境 |
| --- | --- |
| 文字 | 概念、重點、定義 |
| 公式 | 數學、物理、化學 |
| 註記與簡單圖形 | 引線、圈選、箭頭、括號等標示 |
| 雷射筆 | 暫時指出正在講的位置，不留在板書上 |
| 靜態圖表 | 結構、示意圖、標示 |
| 動態動畫 | 波的傳播、物理過程 |
| 互動元件 | 參數調整、模擬實驗 |

規則：

- 一般教學圖表以靜態呈現為主，依照講解內容逐步出現在白板上。
- 特定教學情境可以使用動態演示。
- 專門的互動元件可以讓學生操作。
- AI 自行判斷何時插入互動元件。
- 學生操作互動元件時，不修改原本的教學板書。

以講解波為例，AI 可以：

- 畫出波峰、波谷及平衡位置。
- 用引線標示振幅、波長，並在線的末端寫上短註。
- 講到波峰、波谷時，用雷射筆點出位置，講完光點移開。
- 播放波的傳播動畫。
- 插入可調整振幅、頻率的互動實驗。

## 測驗與檢討

學生要求時，AI 可以依這次已教的內容和原始教材出題、收答，再逐題檢討。講課中途不主動插入測驗。

- 題目範圍落在教材裡，並對應到已經講過的內容。
- 題型由 AI 依觀念決定，可以是選擇、填充或簡答。
- 題目顯示在畫面上。學生用語音或文字作答。
- 作答不修改原本的教學板書。
- 學生答完後進入檢討。AI 逐題說明對錯和理由，可以用語音、雷射筆、既有板書，或追加註記來解釋。
- 檢討時追加的註記留在板書上，規則與一般板書註記相同。
- 檢討結束後，回到測驗前尚未完成的進度。
- 題目、學生的答案和檢討結果要保存，之後可以再看。

## 匯出白板 PDF

學生可以把目前的白板匯出成 PDF。

- 一頁板書對應 PDF 的一頁，順序與白板上的頁面相同。
- 匯出內容包含已寫上的文字、公式、簡單圖形、註記和靜態圖表。
- 動畫以匯出當下的畫面入檔。互動元件以匯出當下的外觀入檔，PDF 裡不能再操作。
- 雷射筆不入檔。逐字稿和教材原文不入檔。
- 文字與公式在 PDF 中保持可讀的電腦字體排版。

## 進度與上課紀錄

- 同一份教材的上課進度要保存。
- 下次打開時，從上次未完成的地方接續。
- 另有一份可回放的上課紀錄，而且可以關閉。
- 紀錄開啟時，回放內容包含：AI 語音、板書過程、雷射筆的移動、學生發言的文字。
- 學生的語音只即時轉成文字。不保存學生的原聲。
- 上課紀錄關閉時，進度仍要保存。紀錄的預設開關尚未指定。

## 產品原則

- 教學內容與白板呈現同步。
- AI 能依照知識類型選擇不同教學方式。
- 學生可以隨時介入，不會失去原本課程進度。
- 不要為了技術方便而限制 AI 的教學方式。
