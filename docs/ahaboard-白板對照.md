# AhaBoard 白板：好在「算出來再畫」，不是手感比較漂亮

日期：2026-11-22

對照他們的數學／物理／作業頁、Thetawave 真實課堂截圖，以及我們現在的備課／講課提示詞與波圖元件。目錄站幾乎沒有真實用戶評語，優點主要來自產品自己反覆講的那句，以及他們願意公開的課堂圖。

> **跟精細圖教學最直接的一句**  
> 他們把「圖要準」從模型繪畫能力拆出去。函數圖是算出來的，不是 LLM 目測一條 SVG。受力圖一次加一支箭。棋盤方格、交點、單位圓都當科目圖元，不是一張自由手繪。我們的波圖元件已經是這條路；通用 `diagram.svg` 還不是。

---

## 1. 白板怎麼畫

### 白板上實際在做的三件事

1. **先算，再畫**  
   數學頁原文：Graphs are computed, not eyeballed。割線 `y=4x−3` 和切線 `y=4x−4` 並排留在板上，交點、斜率不是模型隨便彎一條曲線。

2. **一次只加一個圖元**  
   物理頁：先素描情境，再一支一支加力箭，然後才寫方程式。落地頁拋體示範也是弧線 → 兩顆球 → 受力圖，不是一次倒上整張示意。

3. **圖留著，對話繼續**  
   官方教案寫：盯著一張圖把沒想通的關係問下去。微積分那堂兩條線一直留在板上，所以「斜率相同為什麼不是同一條線」一眼就看見。

### 他們宣傳的科目圖元，對我們現況

| 圖元 | ahaboard 怎麼講 | 我們現在 |
| --- | --- | --- |
| 函數圖／交點 | 由方程式算出來，標出兩條曲線碰頭的位置 | 模型吐 SVG path。viewBox 建議 200×120。沒有 plot 指令 |
| 受力圖 | 物體先畫，力箭一支一支加、有標籤，再用這張圖列式 | 需求有箭頭／角度記號，尚未做成通用元件 |
| 波形 | 運動與波列在物理科目裡，逐步畫 | WaveFigure 已用振幅／波長算出正弦；波峰波谷振幅波長逐步 reveal。這是我們最接近他們的一塊 |
| 棋盤方格／遺傳 | 爸媽各給一個基因，四格一格一格看 | 沒有格子圖元，只能靠自由 SVG |
| 並排比較 | 兩條方程式、抑制劑曲線、歷史天平，留在同一板 | 板書是區塊清單追加，沒有「這兩張圖並排對照」的結構 |
| 重開課時的圖 | 官方承認：圖不一定完整，重開可能不見，課本圖要自己另存 | reveals 存在本機課快照，SVG 會跟著課留下來 |

進度檔第 3 項仍是：簡單圖形元素還沒做成 AI 可選的一套。線、箭頭、括號、點現在只活在波圖裡。

### 我們已經做對的精細圖

`WaveFigure` 不是請模型畫一條像波的線，而是 `sinePath(amplitude, wavelength, phase)` 算出來，再依 `mark-eq`、`mark-crest`、`mark-amp` 逐步加上平衡位置、波峰、振幅箭頭。互動實驗也是改參數重算，不改已寫上的板書。AhaBoard 的函數圖，本質上就是把這套從「波」推到「任意 f(x)」。

## 2. 提示詞差在哪

提示詞其實有兩層。

### 對方公開承認的系統層

開口前先寫私人教案：完整解法、容易出錯的地方、講解順序。圖表用計算，不憑感覺。這層學生看不到，但決定板上會不會畫錯交點。

科目頁把圖元寫進產品契約：數學要能 plot 並標交點；物理要能畫 free-body 且一次一支箭；作業要能指出你寫錯的那一行。

### 對方教學生怎麼下提示

Thetawave 教案給的光合作用提示詞，最後一句被標成最關鍵：

> 用高中程度講光合作用。先問我放出的氧來自哪，再問 ATP／NADPH 怎麼把兩階段連起來。等我回答完，再往下講。

沒有最後一句，得到的是講課；有了它，圖還在板上，學生得自己把箭頭講一遍。

### 我們現在的提示詞實際在要什麼

| 位置 | 現在寫了什麼 | 對精細圖的影響 |
| --- | --- | --- |
| 備課 `planPrompt` | 能畫就用 svg。caption、intent。若真的無法畫，只填 caption 也行。 | 準幾何被允許放棄。模型一覺得難就改成文字圖說 |
| 講課 `boardToolPrompt` | draws 用完整 SVG；path／line／circle／rect／text／polyline；viewBox 約 200×120 | 自由手繪上限太粗。沒有「先給座標再 plot」的通道 |
| 自訂 txt | 只補語氣與生活例子。JSON 工具格式禁止寫進 txt | 風格可調，圖元契約鎖在程式裡，目前契約偏示意而不是計算 |
| `diagram.intent` | 要寫「學生應看懂的重點」，並存進記憶庫 | 教學意圖有了，幾何精度沒有。intent 不能保證交點畫在對的地方 |

### 若要把精細圖教到位，提示詞該改的不是語氣

先禁止「畫不出來就只寫 caption」。再把圖分成兩類：要算的（函數、波形、交點、力的分量）走資料欄位，由前端畫；只要示意的（流程、地圖、生物週期）才走 SVG。系統層補上對方那份私人教案：解法、易錯點、圖元出現順序。學生層則讓「等我答完再畫下一步」變成模式，而不是靠使用者自己寫進輸入框。

## 3. 網路上怎麼說

### 爬文結果：優點很一致，獨立評語幾乎沒有

產品 2026 年 10 月底才上目錄站。Toolify、AlternativeTo、There is an AI for that、AppBrain 都是 0 則用戶評論。Picktool 寫明沒做登入後的實測。所以「白板很好」目前不是社群共識，是他們自己把同一句話鋪到每一頁。

| 來源 | 說了什麼 | 可信度 |
| --- | --- | --- |
| ahaboard.ai 數學／物理／作業頁 | 每一步都畫出來。函數圖算出來。受力圖一次一支箭。開口前先寫教案。 | 第一方，但跨頁用詞穩定，比較像產品契約而不是廣告金句 |
| Thetawave 教案（中英） | 真實課堂：帝王蝶週期圖、光合作用、割線／切線並排、代數只給一則提示。附課堂截圖。 | 仍是官方，但是目前唯一帶圖的深講 |
| 同一篇教案的限制 | 白板上的圖不一定每次完整；重開課圖可能不見。署名與關鍵事實要對課本。 | 官方自己承認的弱點，比讚美更有用 |
| Toolify 繁中頁 | 把「精確繪製圖表／受力圖／潘尼特方格」列成核心功能。流量地理 100% 台灣；平均停留約 8 分半。 | 目錄轉錄，不是實測。停留時間只說明有人真的點進去 |
| TAAFT／AlternativeTo／Play 列表 | 複述 computed graphs。TAAFT 無評分。Android 約 1.5k 安裝、0 則評論。 | 還沒形成口碑，不能當社會證明 |

### 網路上反覆出現、值得當真的優點

**算出來的圖，比畫得像的圖重要。**  
這句在官網 FAQ、數學頁、物理頁、Toolify、TAAFT 都沒有走鐘。獨立評測還沒跟上，但作為白板架構選擇，它解釋了為什麼他們的交點圖能拿來教「斜率相同不是同一條線」，而自由 SVG 很難。

**科目圖元，不是一張萬能畫板。**  
受力圖、棋盤方格、地圖、抑制劑曲線、拋體弧，是分開講的。精細圖教學要的是這份清單，不是更好的「請模型畫 SVG」。

**提示詞分成備課與課堂節奏。**  
系統層先寫解法與易錯點；課堂層用「等我回答」把圖留在板上。官方教案把最後一句標成最關鍵，等於承認：同一個白板，提示詞不對就變講課。
